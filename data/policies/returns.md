# Returns

Which items can come back, and how.

## RET-1 Final sale items
Items marked final sale (our clearance range) cannot be returned or refunded, unless they arrive damaged or we sent the wrong item.

## RET-2 Partial returns
Customers can return some items from an order and keep the rest. Only the returned items are refunded.

## RET-3 Return shipping
We email a prepaid return label once a return is approved. Customers do not pay for return shipping.
