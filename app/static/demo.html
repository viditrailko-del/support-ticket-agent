The AI proposes. Code decides.

A customer email goes to a Gemini agent, which looks up the customer and the order with tools and proposes a refund, replacement, reply or escalation. Then plain code with no AI checks the proposal: whose order it is, what may be refunded, whether the policy quote is real, whether the email tried to give orders. Only safe, small actions run alone; everything else waits for a human.

Email (untrusted)→ Agent looks up and proposes→ Checks in code→ Runs alone or waits for a human
